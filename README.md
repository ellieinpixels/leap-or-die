# Leap Or Die

The code for **Leap Or Die**, a beginner-friendly series on the
[Ellie in Pixels](https://www.youtube.com/@EllieInPixels)
YouTube channel, where we build a complete pixel-art platformer in Godot 4.

Each folder is the finished project at the end of one episode, exactly as it
was built on screen. Open any of them in **Godot 4.6** (Import, then pick the
folder's `project.godot`) to pick up from that point, or to compare with your
own project if something isn't working.

## Episodes

- [`01-setup-first-level`](01-setup-first-level): Episode 01: Setup and First Level
- [`02-player-movement`](02-player-movement): Episode 02: Player Movement
- [`03-wall-jump`](03-wall-jump): Episode 03: Wall Slide and Wall Jump
